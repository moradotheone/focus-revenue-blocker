Política de Privacidad de FocusRevenue

🔒 ARQUITECTURA DE PRIVACIDAD ESTRICTA (ZERO-PII)

Última actualización: 23 de noviembre de 2026

Esta Política de Privacidad describe cómo FocusRevenue («la Extensión», desarrollada por Jorge Morado, contacto: jorge@morado.one) gestiona y protege los datos cuando utilizas nuestra extensión para navegadores basados en Chromium.

1. Propósito Único de la Extensión (Single Purpose)

FocusRevenue tiene un único propósito: ayudar a profesionales independientes, autónomos y creadores a mantener el enfoque en sus tareas de facturación, bloqueando temporalmente sitios web de distracción seleccionados hasta que se alcance la meta económica diaria o semanal acordada.

2. Datos que NO Recopilamos (Zero-PII)

  • Datos personales de tus clientes: La extensión jamás lee, procesa, transfiere ni almacena nombres, correos electrónicos, números de teléfono ni domicilios de los clientes que te pagan.
  • Datos bancarios o de tarjetas de pago: La extensión no recopila números de tarjeta de crédito, cuentas bancarias ni credenciales bancarias.
  • Historial de navegación web: La extensión únicamente intercepta a nivel de red los dominios incluidos expresamente en tu lista negra de bloqueo (por ejemplo, twitter.com o youtube.com) usando chrome.declarativeNetRequest. No rastrea ni registra las webs que visitas fuera de esa lista.
  • Datos de salud médica: El ángulo de enfoque para personas con rasgos de TDAH es estrictamente un marco de autodisciplina y productividad operativa, nunca un servicio médico ni diagnóstico clínico. No se recopilan datos de salud.

3. Datos Técnicos y Almacenamiento Local

Todos los ajustes de la extensión se almacenan estrictamente en tu dispositivo local mediante la API chrome.storage.local:

  • Metas económicas diarias (importe numérico y divisa).
  • Claves de solo lectura de pasarelas de pago (Restricted API Keys de Stripe o credenciales OAuth de PayPal introducidas voluntariamente por el usuario).
  • Metadatos numéricos de transacciones (importe numérico, fecha y fuente) para calcular el progreso diario.
  • Historial de anulaciones de emergencia (motivo ingresado y duración).

4. Comunicaciones de Red y Terceros

  • Stripe API (api.stripe.com): Las llamadas para consultar balances o cobros se realizan directamente desde tu navegador a los servidores oficiales de Stripe mediante HTTPS seguro. Las claves nunca pasan por servidores intermedios de FocusRevenue.
  • PayPal API (api-m.paypal.com): Las consultas se ejecutan directamente con la API REST de PayPal.
  • Pagos a FocusRevenue: Cuando liquidas tu cuota o penalización, el pago se realiza íntegramente dentro de los servidores seguros de Stripe Checkout con cifrado bancario TLS. FocusRevenue no almacena datos de tu tarjeta.

5. Eliminación de Datos y Derechos

Dado que todos tus datos residen únicamente en el almacenamiento local de tu navegador, puedes eliminar la totalidad de tus datos en cualquier momento haciendo clic en «Limpiar Historial» en la consola de la extensión o simplemente desinstalando la extensión de Chrome.
